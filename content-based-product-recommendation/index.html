    THE PRODUCT THINKING

    Personal relevance is
    only half the job.

    01 / CONTEXT

    Too many choices
    feel like no choice.

    With a 10K+ item catalog, broad popularity can bury niche but relevant products. The opportunity was to use the item itself—its category, attributes, and descriptive content—as a useful discovery signal.

    PROBLEM → DISCOVERY OVERLOAD
    02 / APPROACH

    Build features that
    explain the match.

    I represented products through content features and evaluated three recommendation approaches against engagement. The strongest reported variant improved CTR by about 10% over baseline.

    INPUT → CONTENT · OUTPUT → RELEVANCE
    03 / NEXT QUESTION

    Can the system learn
    without narrowing?

    A follow-on reinforcement learning direction could adapt to changing intent. It would need delayed satisfaction and diversity guardrails so repeated clicks do not become the only reward.

    EXTENSION → LONG-TERM VALUE

    WHAT I’D CARRY INTO THE NEXT TEST
    1. 01Keep candidate eligibility consistent across variants.
    2. 02Define the attribution window and primary engagement metric before launch.
    3. 03Track repeat exposure, hides, and category coverage as quality guardrails.
    4. 04Check whether gains hold for new users and long-tail items.

    A CAREFUL EXTENSION

    Where reinforcement learning could fit.

    Use interaction sequences to adapt ranking over time, but optimize for a balanced reward: meaningful engagement, satisfaction signals, and discovery breadth. This is a proposed extension, not a completed RL system.

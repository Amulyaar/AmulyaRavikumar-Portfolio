# Amulya Ravikumar Portfolio

Static GitHub Pages portfolio for Amulya Amblihalli Ravikumar.

**Live site:** https://amulyaar.github.io/AmulyaRavikumar-Portfolio/

The home page links to five selected projects in this repository: ProgramPulse AI, LedgerGuard, Recommendation Health Audit, Discovery Mix Lab, and LaunchReady. Project data and reported outcomes are described in their own READMEs and artifacts; simulation results are identified as synthetic on the site.

## Preview locally

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000/`.

The site is plain HTML and CSS with no build step or runtime dependencies. Fonts are loaded from Google Fonts, with system font fallbacks.
